# My Restaurant

A browser-based 3D restaurant management game built with Vite and Three.js.

## Current features

- Walkable 3D restaurant interior
- Host stand and entrance
- Dining tables and booths
- Kitchen service area
- Decorative lighting and menu boards
- WASD movement and drag camera controls

## Core gameplay direction

Seat customers, prepare food, serve meals, collect payments, and upgrade the restaurant.
